# PRIVATE DRIVE — проверка ролей при входе по SMS

Ветка `feature/flutter-independent-auth` использует отдельный HTTPS-сервер Render и базу `private-drive-test-db`. Сборки GitHub Actions для Android и iOS направляют запросы авторизации на этот сервер.

После подтверждения кода сервер загружает роль из базы по ID аккаунта.

| Роль на сервере | Экран после подтверждения номера |
| --- | --- |
| Аккаунт без служебной роли | Пассажир |
| `pilot` | Кабина пилота |
| `admin` | Кабинет диспетчера |

Назначение служебных ролей выполняется на сервере. Начальный аккаунт владельца создаётся через защищённую операцию для уже подтверждённого аккаунта. Телефон и входные параметры приложения сами по себе не предоставляют повышенных прав.

`GET /health` показывает доступность и состояние отправки SMS. При отключённой отправке `POST /native-auth/request-code` возвращает `503`. Проверки CI используют синтетические данные и заменяют SMS-провайдера.

Мобильные артефакты CI компилируются без подписи. Заказы в кабинетах пока сохраняются локально. Для проверки заказов, чата и геолокации на разных устройствах они должны работать через общий тестовый API с серверной проверкой сессии.
