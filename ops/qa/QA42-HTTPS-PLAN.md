# QA42 HTTPS acceptance environment
CI-only, loopback TLS 443, disposable PostgreSQL, random synthetic bearer sessions, signed synthetic dispatcher identity, no external authentication or payments. Certificate trusted only by the test client; default trust must reject it. No public listener or deployment. Android/iOS share the Dart HTTPS client; CI tests do not prove physical OS trust or background behavior. For device acceptance a separately approved private LAN/VPN host with trusted certificate and synthetic one-time login is required. Existing APK and unsigned iOS bundle use qa.invalid; rebuild with approved origin. No credentials embedded. Browser dispatcher UI remains a separate verified component; this test exercises dispatcher API only.
