# PRIVATE DRIVE — проверка ролей при входе по SMS

Ветка `feature/flutter-independent-auth`. Для проверки используется отдельный HTTPS-сервер с отдельной базой данных.

| Настройка тестового сервера | Кабинет после подтверждения номера |
| --- | --- |
| Телефон отсутствует в списке служебных номеров | Пассажир |
| `PD_NATIVE_PILOT_PHONE` | Пилот |
| `PD_NATIVE_DISPATCHER_PHONE` или существующая настройка `PD_NATIVE_ADMIN_PHONE` | Диспетчер |
| Один номер указан для пилота и диспетчера или администратора | Выбор между двумя кабинетами |

Сервер определяет роль после проверки одноразового кода. Приложение использует роль из ответа сервера. Служебные номера задаются в приватных переменных сервера в формате E.164.

Мобильные сборки CI берут адрес авторизации из переменной репозитория `PD_STAGING_NATIVE_AUTH_API_URL`. Задай HTTPS-адрес тестового сервера после его проверки. Релизные артефакты CI компилируются без подписи.

Проверки Python и Flutter используют синтетические номера и заменяют SMS-провайдера. Они проверяют вход и выбор кабинета. Заказы в этих кабинетах пока сохраняются локально. Проверка рабочих заказов, чата и геолокации между устройствами требует подключения кабинетов к общему тестовому API с проверкой сессии на сервере.
